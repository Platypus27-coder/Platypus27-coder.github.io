# Ngô Gia Huy (YaHi) - Data Science & AI Engineer Portfolio

A modern, cinematic developer portfolio built with React, Vite, Tailwind CSS, Three.js, and Framer Motion.

## 🚀 Live Demo
- [https://platypus27-coder.github.io](https://platypus27-coder.github.io)

## 🛠 Tech Stack
- **Framework**: React 18 & Vite
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js & @react-three/fiber, @react-three/drei
- **Animations**: Framer Motion & GSAP
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Deployment**: GitHub Pages via GitHub Actions

## 📦 Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/Platypus27-coder/platypus27-coder.github.io.git
cd platypus27-coder.github.io

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🌐 Deploy to GitHub Pages
Deployment is fully automated using GitHub Actions (`.github/workflows/deploy.yml`).
Whenever changes are pushed to the `main` branch, GitHub Actions builds and publishes the site to GitHub Pages.
